miQCadj: Basic workflow

Introduction

Filtering cells using strict thresholds for features, counts, and mitochondrial percentages can remove specific cell types or cell states. Therefore, conditional filtering taking complexity information (counts and / or features) and mitochondrial percentages into consideration should be prioritized.

miQC provides a convenient approach overcoming the need for specifying specific cutoffs for complexity information and mitochondrial percentages by fitting a two-component mixture model using flexmix.

miQCadj provides both an implementation of the original miQC classification, and extends the workflow

  • Featuring Seurat and SummarizedExperiment workflows,
  • Supporting median-based identification of intact and compromised model components for spline, polynomial, and polynomial-raw models,
  • Enabling comparisons of model classification, original and geometry-based adjustments by labeling of compromised cell fractions before transferring the selected results back to the input objects.

Running miQCadj using a subset of pbmcsca

This vignette demonstrates the functionality of the miQCadj package using two small example datasets derived from the pbmcsca dataset provided by the SeuratData package.

The included datasets represent peripheral blood mononuclear cells (PBMCs) from two samples processed with different sequencing technologies:

  • pbmc1_Smart-seq2
  • pbmc2_CEL-Seq2

These subsets were selected to illustrate:

  • geometry-based reassignment of misclassified cells
  • differences between intercept- and median-based component selection

The original dataset is available via the SeuratData package.

The meta.data already comprises information regarding the features ("nFeature_RNA"), UMI counts ("nCount_RNA"), and mitochondrial percentages ("percent.mt"). Additionally, we have cell type annotation available ("CellType").

Cell filtering should be performed per sample. Therefore, we define each sample, while converting pbmc2 into a SummarizedExperiment-related object for demonstration purposes:

pbmc1 <- subset(pbmc_sub2, subset=sample_tech=="pbmc1_Smartseq2")
pbmc2 <- subset(pbmc_sub2, subset=sample_tech=="pbmc2_CELSeq2")
pbmc2 <- Seurat::as.SingleCellExperiment(pbmc2)

Default Workflow for linear models

Fit model

First, we select pbmc1 generated with Smartseq2 and apply run_miQCadj():

fm1 <- run_miQCadj(pbmc1)

By default, percent.mt will be selected for mitochondrial percentage information and nFeature_RNA as complexity column for Seurat objects. To use nCount_RNA as complexity column, set complexity_column = "nCount_RNA". By default, a linear model (model_type="linear") will be applied and the component identity will be determined using the fitted intercepts. Median-based component selection will additionally be available for nonlinear models, where intercept-based ordering may not adequately represent the fitted components across the observed complexity range, as shown in the second part of the vignette.

Check components

check_miQC_components(flexmix_list = fm1, sample_name = "pbmc1_Smartseq2")

pbmc1_Smartseq2: miQC Classification and Posterior Probability of a Cell being low Quality

Define Classification

Next, we define a component selection mode and apply a posterior cutoff. We will use the default with component_selection="intercept" and posterior_cutoff= 0.75:

fm1 <-  define_classification(flexmix_list = fm1)

This will add a column miQC.keep with "keep" and "discard" labels. Cells with an invalid-component posterior probability above the selected cutoff are classified as "discard", cells at or below the cutoff are classified as "keep".

Post-hoc adjustments

Post-hoc adjustments are essential for minimizing model-induced classifications artifacts, not favored in filtering of Single Cell Datasets. Very simple scenarios occur in linear datasets, after the discard line crossed the keep line causing removal of high complexity, low mitochondrial reads.

Running adjust_classifications() will strongly reduce such model-related filtering artifacts. We provide an original_check and a geometry_check, which will both be added to the flexmix data frame by default:

fm1 <-  adjust_classification(flexmix_list = fm1)

When using adjust_classification(), the original_check will always keep cells below the intact cell distribution, while the argument enforce_left_cutoff can either be TRUE, which will discard several cells with low or intermediate library complexity and higher mitochondrial percentage, or FALSE which will keep those cells.

The region-related geometry_check performs curve- and distance-based plausibility adjustments, but hasn’t been benchmarked so far, and therefore, it represents an experimental, heuristic adjustment method. So it should be visualized and inspected using check_miQC_predictions(), before being selected and applied.

check_miQC_predictions(flexmix_list = fm1, sample_name = "pbmc1_Smartseq2",
                       add_unadjusted_prediction = TRUE,  
                       add_compared_prediction = TRUE,
                       adjustment_method = NULL)

pbmc1_Smartseq2: Unmodified and Adjusted Cell Predictions

Though both adjustment methods use very distinct approaches for reassigning cells, they provide identical predictions for this sample given all shared cells are either labelled as both_keep or both_discard.

Further diagnostics regarding the specific adjustments made by each adjustment method and the corresponding regions, can be visualized using:

check_miQC_predictions(flexmix_list = fm1, sample_name = "pbmc1_Smartseq2")

pbmc1_Smartseq2: Original and Adjusted Cell Classification

By default, the returned list of plots will be combined using patchwork. To return a list with each plot being separate accessible, set combine_plots=FALSE.

Add back to Seurat object

By default, only the final prediction column will be transferred to input_obj. Given identical results for both adjustment methods, the final prediction column would reveal identical results for any adjustment method selected:

pbmc1 <- add_to_input_obj(flexmix_list = fm1, input_obj = pbmc1, 
                          adjustment_method = "original_check")

The dataset contains 14 megakaryocytes (5.53%). The 5th percentile of the number of detected genes (nFeature_RNA) corresponds to 722.6 genes. Applying this threshold would exclude 13 of the 14 megakaryocytes (92.9%), leaving only one cell of this population:

# Calculate the 5th percentile of detected genes
feature_cutoff <- unname(quantile(meta$nFeature_RNA, probs = 0.05))
sum(meta$CellType == "Megakaryocyte" & meta$nFeature_RNA > feature_cutoff)
#> [1] 1

This example illustrates how global percentile-based filtering can disproportionately affect specific cell populations, even when only a small fraction of the overall dataset is excluded. Therefore, the consequences of QC filtering should be evaluated carefully to avoid unintentionally removing large fractions of biologically relevant cell populations.

Median-selection for non-linear models

The pbmc2 sample uses the Seurat-inherent column names percent.mt and nFeature_RNA, instead of standard naming conventions for SummarizedExperiment- derived objects, which are subsets_mito_percent for mitochondrial percentage information and detected for feature information. Therefore, the column names need to be specified.

By default, the original miQC package uses the intercept for component definition, which can cause incorrect cell selection, if polynomial or spline models are selected:

fm2 <- run_miQCadj(input_obj = pbmc2, percent_mt = "percent.mt", 
                   complexity_column = "nFeature_RNA", 
                   model_type = "polynomial", add_median_selection = TRUE)
check_miQC_components(flexmix_list = fm2, 
                      sample_name = "Intercept-based components for pbmc2_CELSeq2", 
                      combine_plots=TRUE)

Intercept component selection for pbmc2_CELSeq2: miQC Classification and Posterior Probabilities of a Cell being low Quality

Using the intercept for component selection in this sample would make incorrect assignments, loosing high-quality cells, but keeping low-quality cells.

So, we can check the median component selection (use_median_columns = TRUE) using:

check_miQC_components(flexmix_list = fm2, 
                      sample_name = "Median-based components for pbmc2_CELSeq2", 
                      use_median_columns = TRUE)

Median component selection for pbmc2_CELSeq2: miQC Classification and Posterior Probabilities of a Cell being low Quality

The assignments using medians as component selection mode match our biological expectations with low complexity, but high mitochondrial percentage cells belonging to the compromised component. Therefore, we set component_selection = "median", while using the default posterior threshold (posterior_cutoff=0.75):

fm2 <-  define_classification(flexmix_list = fm2, 
                              component_selection = "median")

Afterwards, we adjusted the classification and check the predictions:

fm2 <-  adjust_classification(flexmix_list = fm2)

# check predictions
check_miQC_predictions(flexmix_list = fm2,  sample_name = "pbmc2_CELSeq2",
                       add_unadjusted_prediction = TRUE, 
                       add_compared_prediction = TRUE,
                       adjustment_method = NULL)

Unmodified and Adjusted Cell Predictions for pbmc2_CELSeq2

Apparently, the original and geometry-based adjustment methods produced substantially different classifications for the CEL-Seq2 sample with many cells retained in the geometry_check being discarded by the original_check.

We can check the exact counts using:

addmargins(table(fm2$flexmix_data[["miQC.keep_adj_compared"]]))
#> 
#> both_discard    both_keep    keep_geom          Sum 
#>           13          167           93          273

The strict filtering in the original check is introduced by enforce_left_cutoff=TRUE. Since removing 93 cells, corresponding to a cell fraction of 34.1%, shouldn’t be performed without further checks, we will set enforce_left_cutoff=FALSE. This will keep the left_cutoff information available, without forcing extensive filtering decisions without further quality checks being performed:

# adjust classification
fm2 <-  adjust_classification(flexmix_list = fm2, enforce_left_cutoff = FALSE)

# check predictions
check_miQC_predictions(flexmix_list = fm2, sample_name = "pbmc2_CELSeq2",
                       add_unadjusted_prediction = TRUE, 
                       add_compared_prediction = TRUE,
                       adjustment_method = NULL)

Unmodified and Adjusted Cell Predictions for pbmc2_CELSeq2 (without left cutoff)

Now, both adjustment methods provide identical results, with no adjustments made, given all shared cells are either labelled as both_keep or both_discard.

To check the regions assigned in both adjustment methods we can create the prediction plot for both adjustment methods:

check_miQC_predictions(fm2, sample_name = "pbmc2_CELSeq2")

Median-based Component Selection and Region-Adjustments for pbmc2_CELSeq2 (without left cutoff)

Add back to SingleCellExperiment object

After setting enforce_left_cutoff=FALSE, both adjustment methods provided identical prediction results. To retain all columns from the flexmix data frame enabling further checks, we can set transfer_columns = "all", enabling further checks, i.e. whether specific cell types occupy specific region compartments:

pbmc2 <- add_to_input_obj(flexmix_list = fm2, input_obj = pbmc2,  
                          transfer_columns = "all", 
                          adjustment_method = "geometry_check")
